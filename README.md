# pages

개인용 웹페이지 퍼블리싱 레포. 블로그(`blog`) 레포와는 무관하게, 필요할 때마다 독립된 정적 웹페이지를 이 레포에 폴더 하나씩 추가해서 GitHub Pages로 공개한다.

- 공개 주소: https://birdie-suyong-lim.github.io/pages/
- 각 페이지는 자신만의 하위 폴더에 `index.html`로 둔다 (예: `lottie-viewer/index.html` → `/pages/lottie-viewer/`).
- 루트 `index.html`에 새 페이지 링크를 추가한다.

## 현재 페이지

- [lottie-viewer](lottie-viewer/) — Lottie(JSON) 파일을 폴더/단일 파일로 열어 재생·레이어·에셋·원본 속성을 확인하는 뷰어. 외부 의존성 없는 단일 HTML.
